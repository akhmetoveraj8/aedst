## One codebase, three shapes

The same binary runs in all three shapes; only environment variables change. Start with the first and move to the next only for a measured reason.

## How an event reaches a consumer in another process

The event is a database row first: the producer commits the state change and the delivery jobs in one transaction. Processes pick up only the queues of the units they host.

<Callout type="warn">
  The audit-first job needs a machine identity (a client-credentials client and an `internal` role in the identity provider). Until it is configured, a mutation on a remote owner is refused before any audit row is written.
</Callout>

## Environment cheat sheet

```bash
# the whole monolith (default): nothing set
# a module service that needs tasks elsewhere
AEDST_MODULES=media
AEDST_MODULE_TASKS_URL=http://tasks.internal:8080
# a feature service ("/" is written "__" in the variable)
AEDST_MODULES=social/like
AEDST_MODULE_SOCIAL__COMMENT_URL=http://comment.internal:8080
```
