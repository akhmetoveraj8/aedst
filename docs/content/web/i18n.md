# Web i18n

Cross-platform rules (locales, per-module ownership, content consistency) are in the [i18n overview](/i18n). This page covers only Web.

| | |
|---|---|
| Mechanism | [next-intl](https://next-intl.dev) JSON, one file per locale per module |
| Source of the text | `packages/i18n/<module>/{ar,en,ru,tg,uz}.json`, shared with every platform; edit only there |
| Module catalogs (generated, committed) | `apps/web/shared/i18n/catalogs/<module>/{ar,en,ru,tg,uz}.json`, imported through the `@i18n/*` alias; refresh with `node packages/i18n/build.mjs`, never edit by hand |
| App-shell strings | module `common` in the same catalogs (`@i18n/common/<locale>.json`) |
| Tajik code | `tj` is the app's internal locale; the catalog file is `tg.json` (`sharedLocale()` in `shared/i18n/locales.ts`) |
| Why | Approved stack pick in [Library-First](/library-first#web); Web is the source of truth every other platform ports from. |

## Status

| Module | Catalog |
|---|---|
| Common / app-shell | ✅ module `common` (app), `admin-common`, `marketing-common` |
| Auth | ✅ `modules/auth/i18n` |
| Tasks | ✅ `modules/tasks/i18n` |

Each new module gets its own folder in `packages/i18n` — never add keys to another module's catalog. The `admin` and `marketing` projects read the same catalogs: their shell strings are the modules `admin-common` and `marketing-common`, and `marketing` also owns `marketing` and `legal`. These Web-only modules are marked `["web"]` in `targets.json`. See also [Web architecture](/web/architecture).
