# Android i18n

**Generated catalogs.** In `feature/auth`, `feature/admin`, `feature/notifications`, `feature/search` and `feature/tasks`, `values*/strings.xml` is generated from `packages/i18n` (header `GENERATED`): never edit it, change the shared JSON and run `node packages/i18n/build.mjs --write-android`. `values*/strings_local.xml` holds the few hand-written leftovers the format cannot express. The same holds for `app`, `core/ui` (`aedst_*`), `core/media` and `feature/media`. Only `app-tv` is hand-written (its sole string is the non-translatable `app_name`). Resource-name prefixes per module are in `ANDROID_HOMES` (`packages/i18n/lib/targets.mjs`).

Cross-platform rules (locales, per-module ownership, content consistency) are in the [i18n overview](/i18n). This page covers only Android.

| | |
|---|---|
| Mechanism | Android resource qualifiers: per-module `res/values*/strings.xml` |
| Module catalogs | `feature/<name>/src/main/res/values{,-ru,-ar,-tg,-uz}/strings.xml`; the unqualified `values/` is **English** (the fallback for a device language the app does not ship), Russian is `values-ru/` |
| App-shell strings | `app/src/main/res/values*/strings.xml` (`common_*` keys) |
| Per-app language | `androidResources.generateLocaleConfig = true` (application convention plugin) builds `res/xml/_generated_res_locale_config` from the `values-<locale>` folders; `res/resources.properties` in `app` and `app-tv` sets `unqualifiedResLocale=en` (the unqualified `values/` is English). The system language picker therefore offers exactly en, ru, tg, uz, ar |
| Why | This is the platform API: Android merges resources by name across modules at build time, so no third-party library is needed. |

## Status

| Module | Catalog |
|---|---|
| Common / app-shell | ✅ `app/src/main/res/values*` |
| Auth | ✅ `feature/auth` (`auth_*` keys, used in `LoginScreen.kt`) |
| Tasks, Admin, Media, Notifications, Search | ✅ `feature/<name>/src/main/res/values*` (all five locale directories each) |
| Shared (`core/ui`, `core/media`) | ✅ `core/<name>/src/main/res/values*` (`aedst_action_ok/cancel/confirm/retry` in `core/ui`) |
