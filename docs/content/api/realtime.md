## RealtimeService

RealtimeService answers the realtime gateway (apps/gateway, ADR-0026): when a
client opens a WebSocket, the gateway calls GetConnectionAccess with the
client's own access token as the bearer. The Go server verifies the token
with its usual interceptor, so it stays the only OIDC resource server
(ADR-0019); the gateway verifies nothing itself.

Mounted only when the NATS bridge is enabled (AEDST_NATS_URL). Any signed-in
caller may call it and only learns about itself, so it needs no role; a
deployment can still close it with AEDST_ROLE_POLICY
("/aedst.realtime.v1.RealtimeService/*=<role>"). The per-user rate limit
applies as to every authenticated RPC.

### GetConnectionAccess

Returns the owner id the caller's events are addressed to and the instant
the caller's access token expires, at which the gateway closes the socket.
Reads only the verified token: no database access, no side effects.

> No side effects: also callable as a Connect `GET`, see [conditional reads](/engineering/api-design#conditional-reads-and-caching).

**Request** `GetConnectionAccessRequest`

_No fields._

**Response** `GetConnectionAccessResponse`

| Field | Type | Constraints | Description |
|---|---|---|---|
| `user_id` | `string` | — | Owner id (UUID) of the caller, the recipient part of the NATS subject aedst.events.user.<user_id>.<event type>. |
| `expires_at` | `google.protobuf.Timestamp` | — | When the caller's access token expires (its "exp" claim). The gateway closes the socket at this instant (close code 4401); the client reconnects with a fresh token. |

Example:

```bash
curl -sS "$AEDST_URL/aedst.realtime.v1.RealtimeService/GetConnectionAccess" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -H "Connect-Protocol-Version: 1" \
  -d '{}'
```

```json
{

  "expiresAt": "2026-11-19T09:30:00Z"
}
```
