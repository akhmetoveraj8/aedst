# Event ingest API

Package `aedst.events.v1` · source `apps/server/api/proto/aedst/events/v1/` · conventions, authentication and errors: [API overview](/api).

## EventIngestService

EventIngestService is the wire contract for an integration event that crosses a
database boundary (ADR-0022). A producer whose consumer lives in another
service does not insert the consumer's delivery in its own River tables: it
inserts a platform.event_forward job in the same transaction as the state
change, and that job calls Deliver on the consumer's service. The consumer's
service inserts the real delivery job in its own database, so each side keeps
its own outbox and retry lifecycle and no distributed transaction exists.

The service is closed to users: only the machine identity (role "internal",
see AEDST_SERVICE_IDENTITY_*) may call it, and it is mounted only when
AEDST_EVENTS_INGEST_ENABLED is true. The event payload stays the JSON the
producing module serialises (pinned by its golden fixtures); this envelope is
what buf breaking guards.

### Deliver

Deliver records one event delivery for one consumer. It is idempotent on
(consumer, event_id): replaying it (the producer retries after a lost
response) never creates a second delivery. An unknown consumer is NOT_FOUND
and a malformed envelope INVALID_ARGUMENT; both are permanent, the producer
does not retry them.

**Request** `DeliverRequest`

| Field | Type | Constraints | Description |
|---|---|---|---|
| `consumer` | `string` | min length 3, max length 128 | Stable consumer name "<unit>.<name>", e.g. "notifications.task_completed". |
| `event_id` | `string` | UUID | Event id (UUID), stable across redeliveries; the consumer dedupes on it. |
| `event_type` | `string` | min length 1, max length 128 | Event type, e.g. "tasks.v1.TaskCompleted". |
| `event_version` | `uint32` | — | — |
| `occurred_at` | `google.protobuf.Timestamp` | required | — |
| `partition_key` | `string` | UUID | Aggregate id (UUID) the event is partitioned by. |
| `traceparent` | `string` | max length 128 | W3C traceparent of the originating request; empty if none. |
| `payload` | `bytes` | max length 262144 | The event payload exactly as the producing module serialised it (JSON). |

**Response** `DeliverResponse`

| Field | Type | Constraints | Description |
|---|---|---|---|
| `created` | `bool` | — | True when this call created the delivery, false when it already existed. |
