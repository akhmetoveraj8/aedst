## IntegrityService

IntegrityService verifies Google Play Integrity (STANDARD API) tokens
minted by the Android app (core/security PlayIntegrityFacade). The server
decodes the token with Google (playintegrity.googleapis.com
v1/{package}:decodeIntegrityToken), then applies its own policy: package
name, freshness, request binding, device/app/licensing verdicts, replay.

Authenticated callers only. Disabled until AEDST_INTEGRITY_ENABLED=true
(FAILED_PRECONDITION while disabled). A token that fails the policy is NOT
an RPC error: the call succeeds with verified=false and a reason, so the
client can decide what to do (block, degrade, ask for a retry).

### VerifyIntegrityToken

Decodes a Play Integrity token with Google and applies the server policy.
A token that fails the policy answers verified=false with a reason, not an error.

**Request** `VerifyIntegrityTokenRequest`

| Field | Type | Constraints | Description |
|---|---|---|---|
| `integrity_token` | `string` | min length 1, max length 32768 | The opaque token from StandardIntegrityToken.token(). Never logged. |
| `action` | `string` | min length 1, max length 64, pattern ^[a-z][a-z0-9._-]*$ | What the token authorises, e.g. "login" or "purchase". Part of the bound hash. |
| `payload` | `bytes` | max length 4096 | Caller-chosen bytes the token is bound to (include a fresh nonce). |
| `request_hash` | `string` | length 43, pattern ^[A-Za-z0-9_-]+$ | The value given to setRequestHash: base64url (no padding) SHA-256, 43 chars. |
| `package_name` | `string` | max length 255, pattern ^([A-Za-z][A-Za-z0-9_]*(\.[A-Za-z][A-Za-z0-9_]*)*)?$ | The app's applicationId. Empty means "the only allowed package" and is rejected when AEDST_INTEGRITY_ALLOWED_PACKAGES lists several. Must be one of the allowed packages; Google also checks the token was minted for it. |

**Response** `VerifyIntegrityTokenResponse`

| Field | Type | Constraints | Description |

| `verified` | `bool` | — | — |
| `reason` | [FailureReason](#failurereason) | — | — |
| `device_verdicts` | list of [DeviceVerdict](#deviceverdict) | — | What Google reported (present whenever the token was decoded). |
| `app_verdict` | [AppVerdict](#appverdict) | — | — |

Example:

```bash
curl -sS "$AEDST_URL/aedst.integrity.v1.IntegrityService/VerifyIntegrityToken" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -H "Connect-Protocol-Version: 1" \
  -d '{
  "integrityToken": "integrity token",
  "action": "action",
  "payload": "c2FtcGxl",
  "requestHash": "request hash",
  "packageName": "package name"
}'
```
