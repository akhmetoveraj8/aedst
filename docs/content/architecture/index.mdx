## The five ideas that explain everything

1. **Monolith first, boundaries first** ([ADR-0001](/decisions/0001-modular-monolith)). One deployable, many modules with enforced borders. Any module can become a service later without a rewrite.
2. **Contract first** ([ADR-0002](/decisions/0002-connectrpc)). Every API is a `.proto`; server stubs, five client stacks and this site's [API reference](/api) are generated from it.
3. **Stateless compute, stateful data.** Pods keep no session, so scaling compute is adding replicas; the database is the one shared bottleneck and is protected deliberately ([Scalability](/architecture/scalability)).
4. **Events through the database.** A state change and the events it causes commit in one transaction (River `InsertTx`), so nothing is lost and nothing is published twice ([Data and events](/architecture/data-and-events)).
5. **Identity is rented, not built** ([ADR-0019](/server/architecture)). An OIDC provider authenticates; the server authorizes ([Security](/architecture/security)).

## Honest status

Server and Web are built and tested. Android ran on a JVM only, Apple and Desktop were never compiled, the Rust gateway has not been built on the authoring machine, and the Kubernetes manifests were not applied to a cluster. Diagrams show the **designed** system; [Platform status](/status) says what was run.
