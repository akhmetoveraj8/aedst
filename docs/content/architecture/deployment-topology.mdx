## Implemented versus planned

| Item | State |
|---|---|
| Helm chart, PgBouncer, CloudNativePG overlay, imgproxy, alerts | Written; not applied to a cluster |
| Dockerfile and migration image | Written; CI build is the test |
| OpenTofu modules, Argo CD, deploy pipeline | Not implemented |
| Realtime gateway | Written; Rust gates not run on the authoring machine |
