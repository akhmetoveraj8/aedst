## Ports and protocols

| Port | Protocol | Purpose |
|---|---|---|
| `8080` | HTTP/1.1 and HTTP/2, Connect, gRPC, gRPC-Web, JSON | The API, `/healthz`, `/readyz` |
| `9090` | HTTP | Prometheus `/metrics` (optional) |
| `3000`, `3001`, `3002` | HTTP | Web `app`, `admin`, `marketing` (dev defaults) |
| gateway | WebSocket | Realtime nudges, authenticated with the same access token |

Every environment variable that changes this shape is in [Configuration](/server/config). The three process shapes (monolith, module services, feature services) are in [Backend diagrams](/server/diagrams).
