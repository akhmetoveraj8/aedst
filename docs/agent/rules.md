# AEDST agent rules (full text)

Read these before modifying any code in this repository:

1. **[CONVENTIONS.md](../../CONVENTIONS.md)** — naming standard for all 5 platforms (Web, Server, Android, Apple, Desktop). File/type/function/constant naming is a **Must**, enforced by linters and `scripts/check-naming.sh`.
2. **[docs/content/library-first.md](../content/library-first.md)** — AEDST Library-First Development Standard: the approved stack per platform, the mandatory order of preference (standard library → platform API → existing AEDST dependency → approved library → custom code), the version policy, the explicit rejections, and the monorepo tooling rules.
3. **[docs/content/decisions.md](../content/decisions.md)** — index of architectural decisions with rationale and "when to revisit". If a proposal contradicts it, do not implement or re-propose it.
4. **[docs/agent/quality-bar.md](quality-bar.md)** — the engineering standard in short form: write for the pinned toolchain with its modern features (no experimental ones), design APIs contract-first (`api-design` skill), keep every security and performance gate, and run the `quality-pass` skill before reporting done. Full text: `docs/content/engineering/` (modern-language, api-design, security, performance).
5. The `AGENTS.md` inside the app you touch (e.g. `apps/server/AGENTS.md`, `apps/web/AGENTS.md`) and platform ADRs (`apps/server/docs/adr/`, `apps/desktop/docs/adr/`).

## Core first

**Server (backend) and Web first.** Build and verify every feature on Server + Web before starting any other platform; Android, Apple, Desktop and Gateway follow only after Core is green. "Green" means the Server and Web gates (`task verify:server`, `task verify:web`) pass and the feature row in `features.yaml` is complete for `server` and `web`. Until then the other platforms get `~` (not started) in `features.yaml`, never a half-port. Every other file states this rule in one line and links here.

## The one rule that matters most

**Do not write code that an existing library or platform already does.** Before creating a utility, hook, component, service, repository, parser, formatter, validator, or any other new abstraction: check the standard library, the platform API, the libraries already in this repo's `package.json`/`go.mod`/`build.gradle.kts`/`Package.swift`/`Cargo.toml`, and the existing code in this repo — in that order. Only write custom code when none of those fit, and only for a documented technical reason (missing functionality, unsupported platform, incompatible API, unacceptable performance, security/compliance requirement, project-specific domain logic) — never "it's simpler to write myself" or "it's only 50 lines."

This applies to every platform in this repo:
- **Web**: React Hook Form (forms), Protovalidate via `protovalidateResolver` (API-message forms) and Zod (client-only data, env); the boundary and its gates are in `docs/content/web/validation.md`, date-fns (dates), dnd-kit (drag & drop), shadcn/ui via `apps/web/shared/ui/` (UI), TanStack Query/Table/Virtual, nuqs (URL state). Biome is the only linter/formatter.
- **Server**: govips+libvips (image ingest only, build tag `vips`) + imgproxy (on-demand delivery), never the same operation in both (ADR-0015), net/http ServeMux (+ realclientip-go, rs/cors), Protobuf+Buf+ConnectRPC, Protovalidate, pgx+sqlc+Goose, River (deferred jobs and, via `InsertTx` in the producer's transaction, integration events - `internal/platform/events`, ADR-0014), Postgres advisory locks, DragonflyDB (cache/rate limit only), jwx (OIDC resource server), OpenTelemetry (OTLP), caarlos0/env.
- **Android**: Jetpack Compose, Metro, Coroutines+Flow, connect-kotlin over OkHttp, Keystore + Tink, `apps/android/core/ui/`.
- **Apple**: SwiftUI with native Observation (`@Observable`) and `NavigationStack`, GRDB, connect-swift, Nuke (images, only via `Core/AedstMedia`), Tuist, fastlane + match (signing/release), swift-format + SwiftLint, `apps/apple/Core/AedstDesignSystem/`. Min OS iOS/iPadOS 18, macOS 15 (single source: `apps/apple/Project.swift`).
- **Desktop**: Rust + Slint in `apps/desktop` (ADR-0001 there): `connectrpc`, `openidconnect`, `keyring`, `velopack`, `rusqlite`, `tracing`, workspace dependencies only.

Full stack tables, anti-patterns, and the AI Definition-of-Done checklist are in `docs/content/library-first.md`.

## UI kit only

Feature code uses UI kit components only (`docs/content/ui-kit.md`). Web: no raw `<button>`, `<input>`, `<select>`, `<textarea>`, `<label>`, `<form>`, `<table>`, `<dialog>` and no direct import of the primitive libraries behind the kit (radix-ui, @base-ui/react, cmdk, ...) outside `apps/web/shared/ui`. Android: no raw Material 3 controls outside `core/ui`. Apple: no raw SwiftUI controls or `.sheet`/`.alert` outside `AedstDesignSystem`. Desktop: no `std-widgets.slint` outside `aedst-ui`. A missing component is added to the kit first, never built inline. Gate: `task check:ui-kit-only`; the only exemption is a `ui-kit-ignore: <reason>` comment, and the Apple debt in `scripts/ui-kit-only.baseline` may only shrink.

## Translations: one JSON format on every platform

Every app that shows text uses the same JSON translation files (`packages/i18n/<module>/{en,ru,tg,uz,ar}.json`, nested camelCase keys, ICU `{name}` placeholders), so a translation written for one platform works unchanged on every other. Native catalogs (`strings.xml`, `.xcstrings`, `.po`) are generated from them, never hand-edited or hand-copied; a string is written and translated once. Full rule and honest migration status (not yet implemented outside Web): [i18n](../content/i18n.md#one-json-translation-format-on-every-platform-mandatory).

## Mandatory process rules

- **Versions**: latest stable, verified against the registry. Never invent or guess a version; if you cannot verify it, say `UNVERIFIED`.
- **Approved before first use is machine-enforced**: knip allowlist (`apps/web/app/knip.jsonc`) on Web; `go mod tidy` + golangci-lint `depguard` on Server. **Adding to any allowlist requires updating `docs/content/library-first.md` in the same change.**
- **Monorepo tooling** : `mise.toml` pins toolchains; root `Taskfile.yml` (with per-app includes) is the single entry point, so use `task ...` instead of ad-hoc commands; design tokens come from `packages/design-tokens` (Style Dictionary) and generated token files must never be hand-edited.
- **Honesty about verification**: only Server and Web (Core) are verified. Android compiles (2026-11-25) but `assembleDebug`, part of the tests and device runs are UNVERIFIED; Apple was never compiled; Desktop passes its gates on Windows only; Gateway is EXPERIMENTAL (off by default; compiled and tested on Windows only, 2026-11-28; CI never green). Do not claim they build. Source of truth: [status](../content/status.md).
- **Docs are the source of truth**: when you change an architectural decision, update `library-first.md` and `decisions.md` in the same change.
- **Docs ownership and drift**: `/docs/` is owned through `.github/CODEOWNERS`; a PR that changes a documented rule, path or command changes the doc in the same diff (the PR template asks). `task check:docs` fails on broken links, repo paths that no longer exist, missing front matter and stray Cyrillic. A decision row without a "Revisit when" is incomplete. When a path in a doc and the code disagree, the code wins and the doc is fixed in that PR.
- **Working tree hygiene**: commit in atomic steps (one move or one concern per commit, generated files with their source). A large uncommitted tree has no rollback; the SessionStart hook warns above 200 changed files. Agents never commit, stash, reset or switch branches unless the user asks (several sessions can share one tree). When asked to commit, stage only the files this session changed, by path (`git add <path>`; bulk `git add -A` / `.` / `-u` and `git commit -a` are refused by `.claude/hooks/pre-bash-guard.sh`), and read `git diff --staged` before committing. **Never revert, overwrite or "fix" an uncommitted change you did not make**: if another session's change breaks your gate (an install, a build, a test), stop, name the file and the failure, and ask the user; do not roll it back to get green. Parallel sessions that write code belong in separate git worktrees.

## Decision records / forbidden list

Rationale and revisit conditions for everything below: [docs/content/decisions.md](../content/decisions.md). Do **not** introduce or re-propose:

- **Server**: `golang.org/x/image` or pre-generated generic image renditions (govips sanitizes the original, imgproxy resizes - ADR-0015); Redis (use DragonflyDB, cache/rate-limit only, never correctness); RedSync/Redlock or any DragonflyDB lock (use `internal/platform/lock`); Kafka/RabbitMQ, and NATS anywhere except `internal/platform/natsbridge` (events are River `InsertTx` jobs via `internal/platform/events`, ADR-0014; JetStream only carries allowlisted types to the Rust gateway, ADR-0021; never publish from request handlers outside the producing transaction); a hand-built outbox/relay/in-process bus/inbox (superseded by ADR-0014); a second JWT/JOSE library, or JWT verification outside `internal/platform/auth` (the Rust gateway asks `RealtimeService`, ADR-0026); backend code in Rust without the ADR-0025 criteria (profile, tuned Go, Protobuf contract, off switch); an ORM; Prometheus-specific instrumentation; trusting `X-Forwarded-For`/`X-Real-IP` blindly (use the realclientip trusted-hop strategy via `internal/platform/clientip`); chi or any third-party router (use `net/http` ServeMux); self-built identity features (MFA, recovery, social login) — ZITADEL is the default IdP (Keycloak is the alternative if a project bans AGPL), first-party auth is off by default (`AEDST_AUTH_FIRST_PARTY_ENABLED=false`) and time-boxed by `AEDST_AUTH_FIRST_PARTY_SUNSET`; self-hosted Tempo/Loki/Pyroscope by default.
- **Web**: RxJS (use TanStack Query, `AbortController`, async iterators, Connect streaming); ESLint/Prettier (Biome only); test/dev packages outside `devDependencies`; a new third-party origin without adding it to the CSP in `apps/web/app/next.config.ts`.
- **Android**: any DI other than Metro (Metro is the only DI: no Koin, Dagger or manual service locators); `security-crypto`/`EncryptedSharedPreferences` (use Keystore + Tink); Retrofit; `tv-foundation` lists; running on JDK other than 21.
- **Apple**: XcodeGen/`project.yml` (use Tuist); SwiftData (use GRDB: explicit versioned migrations and control); swift-perception / FlowStacks (removed - native Observation and `NavigationStack`); the hand-written image loader (use Nuke via `Core/AedstMedia`); SwiftFormat (nicklockwood) / Periphery (swift-format + SwiftLint); `ASAuthorizationPlatformPublicKeyCredentialProvider` for passkeys (a self-built identity feature - passkeys come from the IdP's hosted login); a second session-replay tool (PostHog is the only one on iOS); swift-dependencies is not adopted yet (decisions.md, "when to revisit"). `grpc-swift-2` as primary transport is an owner decision (connect-swift), no longer an OS-floor issue.
- **Desktop** (`apps/desktop`): Rust + Slint only: no other language or UI toolkit, no FFI UI bindings, no Tauri/WebView (owner chose Slint); a hand-written Connect or OIDC client; hand-mirrored DTOs; committing generated code; `unwrap()` and `unsafe`.
- **Infrastructure as code**: Terraform (BSL) - OpenTofu is the single IaC tool (`infra/`, `.terraform.lock.hcl` committed, providers pinned, one S3-compatible remote state backend with locking); no Pulumi/CDK/second tool.
- **Kept by owner decision (do not propose replacing)**: Next.js for `app` and `marketing` (`admin` is a Vite SPA with TanStack Router and a Hono BFF), React Hook Form, the `cn` npm package, Goose (Atlas is paid), Rust + Slint on Desktop, Metro on Android. See "Explicit rejections" in `library-first.md`.
