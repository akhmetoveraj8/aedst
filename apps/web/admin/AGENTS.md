## Rules that bite

- Validation boundary ([docs/content/web/validation.md](../../../docs/content/web/validation.md)): API-message forms use `protovalidateResolver` only (rules live in the `.proto`); Zod is for env/storage/non-proto input and never imported in `ui/**`; React Hook Form is state only (no `register(..., {rules})`, no `rules=`, every `useForm` has a `resolver`). Enforced by Biome plugins and `pnpm check:validation`.
- Admin never stores tokens in the browser: its own httpOnly `__Host-` cookies (never shared with `app`), handled in `shared/lib/auth` and `src/proxy.ts`.
  Admin is its OWN OIDC client (`OIDC_CLIENT_ID=aedst-admin`, cookie `AUTH_COOKIE_NAME=aedst_admin_session`, redirect `${ADMIN_ORIGIN}/api/auth/callback`): `src/app/api/auth/{login,callback}` + `modules/admin` sign-out, never the app's session. Anonymous -> `/api/auth/login?next=`.
- Every admin action needs a server-side RoleInterceptor check in apps/server. The UI role check is cosmetic and never enough.
- Admin is never indexed: `robots: noindex` metadata, `X-Robots-Tag` from `proxy.ts`, `robots.ts` disallows all. Do not add a sitemap, `llms.txt`, JSON-LD or OpenGraph.
- No PWA, service worker, offline outbox, PostHog or consent banner here. Do not copy them from `app`.
- Never import from `../app` or `../landing` (`pnpm check:deps` fails). Need it in two projects: move it to `../shared` (only `@/shared/*` imports inside it).
- `@/shared/*` resolves to `../shared/*` and must stay the first `paths` entry in `tsconfig.json` (and the first alias in `vitest.config.mts`).
- Do not hand-edit generated files: `shared/api/connect/generated/**` (`task web:generate`), `shared/ui/tokens.css`, `next-env.d.ts`.
- Biome is the root `../biome.json` (do not create one here). Versions are `catalog:` in `../pnpm-workspace.yaml`; never a literal version.
- A new dependency: allowlist it in `knip.jsonc` and the Library-First page in the same change.
- Files stay at or under 300 lines (over 500 fails `task check:file-size`).

## Gates (run before saying done)

1. In `apps/web/admin`: `pnpm lint`, `pnpm typecheck`, `pnpm knip`, `pnpm check:deps`, `pnpm test` (browser tests need `pnpm test:browser:install` once).
2. `task check` from the repo root (naming, file size, colors, i18n parity, boundaries).
3. `pnpm build` after a change to `next.config.ts`, `proxy.ts`, `csp.ts` or routes.
4. Claim only what ran.
